# Assets

Drop your images here. The site references these filenames — just add files with
these exact names and they appear automatically (until then, styled placeholders show):

| Filename        | Used for                        | Suggested size      |
|-----------------|---------------------------------|---------------------|
| `hero.jpg`      | Big hero portrait               | ~800 × 1000 (portrait) |
| `about.jpg`     | About-section photo             | ~800 × 1000 (portrait) |
| `work-1.jpg`    | Featured project (large)        | ~1600 × 700 (wide)  |
| `work-2.jpg`    | Featured project                | ~1000 × 640         |
| `work-3.jpg`    | Featured project                | ~1000 × 640         |
| `work-4.jpg`    | Featured project                | ~1000 × 640         |
| `work-5.jpg`    | Featured project (wide)         | ~1600 × 640 (wide)  |

You can also use `.png` — just update the `src` in `index.html` to match.
